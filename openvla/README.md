# Put your OpenVLA checkout here

BOSS no longer vendors OpenVLA. Clone it into this folder and run the installer:

```shell
git clone https://github.com/openvla/openvla.git .
cd .. && python integrations/openvla/install.py
```

See [`integrations/openvla/README.md`](../integrations/openvla/README.md) for what
the installer does and how to fine-tune and evaluate.

Everything in this folder except this README is git-ignored.
